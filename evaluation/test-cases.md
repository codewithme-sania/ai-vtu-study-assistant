# Prompt Evaluation — Test Cases

## Baseline Prompt

The baseline prompt is tested against common ECE learning requirements.

---

## Test Case 01 — Concept Explanation

**Input:**

Explain MOSFET.

**Expected behavior:**

The response should provide a clear explanation of MOSFET,
including its basic structure, working principle, and important
technical concepts.

---

## Test Case 02 — Short Answer

**Input:**

Give me a 2-mark answer for MOSFET.

**Expected behavior:**

The response should be concise and suitable for a 2-mark
examination answer.

---

## Test Case 03 — Long Answer

**Input:**

Give me a 10-mark answer for MOSFET.

**Expected behavior:**

The response should provide a detailed and well-structured
explanation suitable for a long-answer examination question.

---

## Test Case 04 — Revision

**Input:**

Give me quick revision notes for MOSFET.

**Expected behavior:**

The response should contain concise key points, definitions,
important concepts, and formulas where relevant.

---

## Test Case 05 — Practice

**Input:**

Generate practice questions on MOSFET.

**Expected behavior:**

The response should generate relevant ECE-level questions
covering different difficulty levels.
