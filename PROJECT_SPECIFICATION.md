# AI VTU Study Assistant — Project Specification

## 1. Project Overview

The AI VTU Study Assistant is a prompt-engineered AI system designed to help VTU engineering students understand academic concepts, prepare examination-oriented answers, and revise subjects efficiently.

The project focuses on designing, testing, and evaluating structured prompts rather than simply generating generic AI responses.

---

## 2. Problem Statement

VTU students often need the same academic topic explained in different ways depending on their learning and examination requirements.

For example, a student may need:

- A simple conceptual explanation
- A short 2-mark answer
- A medium 5-mark answer
- A detailed 10-mark answer
- Quick revision notes
- Important keywords
- Practice questions

Generic AI prompts may produce inconsistent answers in terms of depth, structure, technical accuracy, and examination relevance.

---

## 3. Proposed Solution

The project develops a structured prompt system that controls the AI's:

- Role
- Context
- Response depth
- Answer format
- Difficulty level
- Examination orientation
- Technical terminology
- Output constraints

The system will provide different response modes depending on the student's requirement.

---

## 4. Core Features

### Concept Explanation
Provides clear explanations of engineering concepts.

### Exam Answer Generator
Generates structured answers suitable for different mark allocations.

### Quick Revision
Converts concepts into concise revision notes.

### Key Points
Extracts important definitions, formulas, concepts, and keywords.

### Practice Questions
Generates questions to help students test their understanding.

### Exam Mode
Focuses responses on important examination-oriented information.

---

## 5. Prompt Engineering Techniques

The project will demonstrate:

- Role prompting
- Context injection
- Instruction design
- Few-shot prompting
- Structured output prompting
- Constraint-based prompting
- Prompt decomposition
- Prompt iteration
- Edge-case testing
- Prompt evaluation

---

## 6. Evaluation Criteria

Prompts will be evaluated based on:

- Accuracy
- Relevance
- Completeness
- Clarity
- Structure
- Exam usefulness
- Consistency

---

## 7. Project Goal

The goal is to demonstrate how systematic prompt engineering can transform a generic AI assistant into a specialized academic assistant for VTU students.

---

## 8. Future Improvements

Potential future improvements include:

- Integration with VTU syllabus and study materials
- PDF/notes-based question answering
- Retrieval-Augmented Generation (RAG)
- Interactive web interface
- Automated prompt evaluation
- Subject-specific assistants
